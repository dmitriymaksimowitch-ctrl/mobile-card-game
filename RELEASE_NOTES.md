# Карточный клуб 1 — 1.0.1

Изменения относительно 1.0.0:
- Колода оформлена плотной стопкой; козырь лежит под ней перпендикулярно и выступает справа.
- Карты в руке подстраиваются по размеру, чтобы помещаться по ширине экрана.
- Анимации перелёта карт замедлены в реализованных игровых режимах.
- Добавлены автоматические проверки и сборка Android APK через GitHub Actions.

Идентификатор Android-приложения остаётся `org.cardclub.mobilegame.v1`.
Обновление устанавливается поверх 1.0.0 только при подписи тем же ключом.

## Автоматическая публикация

См. ANDROID_RELEASE.md. APK собирается после изменений в main.
Подписанная сборка публикуется как GitHub Release только при наличии
GitHub Actions Secret `CARD_CLUB_SIGNING_ARCHIVE_B64`.
Без этого секрета сохраняется только неподписанный APK для диагностики.

# Карточный клуб 1 — 1.0.0

Первая версия новой линии приложения. Android package: org.cardclub.mobilegame.v1.
versionName 1.0.0, versionCode 1. Устанавливается рядом со старой игрой.

Изменения: новый общий дизайн, крупные прямые карты, центрирование игрового стола,
адаптация к пропорциям экрана, сортировка по мастям и достоинству (козыри справа),
отмена подсказок допустимого хода, дрожание при неверном ходе, пауза перед
завершением раунда в дураке и последним результатом в девятке, ускорение анимаций.

## Сборка и дальнейшие обновления
Godot 4.7.2 stable, Android export templates той же версии; Java 17 и Android build-tools 35.
Экспорт: godot --headless --path . --export-release Android build/card-club-1.0.0.apk
Экспорт создаёт неподписанный APK. Затем подписать apksigner сохранённым ключом
из отдельного приватного архива card-club-signing-recovery.zip (alias cardclub).
Ключ и пароль намеренно отсутствуют в исходниках. Не публикуйте приватный архив.
Для обновления сохранить package и ключ, повысить version/code и version/name,
обновить номер версии в меню main.gd и project.godot.

## Проверка
Запуск всех режимов, тесты tests/release_checks.gd, визуальная проверка дурака
на экране 540×1200, проверка подписи APK. На физическом Android не тестировалось.
Исходники основаны на GitHub commit dc3c7d60480bfdfe51c3de912f2763461efeba74.
При подготовке APK 15 октября запись в GitHub была недоступна (403).
22 октября подключение восстановлено, исходники перенесены в ветку release/card-club-1.0.0.
