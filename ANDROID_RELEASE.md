# Автоматическая сборка Android-приложения «Карточный клуб 1»

GitHub Actions собирает проект Godot 4.7.2 после каждого изменения в `main`
и по ручному запуску. Для обновления установленной версии 1.0.0
используется **тот же** приватный ключ подписи.

## Однократная настройка подписи

В репозитории **не хранится** ключ подписи. Он находится в личном
резервном архиве `card-club-signing-recovery.zip` (архив не публиковать).

1. Закодируйте весь архив одной строкой Base64 (без пробелов и перевода строки).
   Пример: `base64 -w 0 card-club-signing-recovery.zip` на Linux.
   В Windows PowerShell:
   `[Convert]::ToBase64String([IO.File]::ReadAllBytes("card-club-signing-recovery.zip"))`
2. В GitHub откройте `Settings → Secrets and variables → Actions → New repository secret`.
3. Name: `CARD_CLUB_SIGNING_ARCHIVE_B64`.
4. Secret: Base64-строка из пункта 1. Сохраните.
5. Откройте вкладку `Actions → Build Card Club Android APK → Run workflow`,
   выберите ветку `main` и запустите.

Сборка **не публикует подписанный APK**, если секрет отсутствует. В этом
случае только загружает неподписанный файл для диагностики.
GitHub Secrets не выводятся в журнал и не включаются в релизы.
Не помещайте пароль/ключ в файлы репозитория и сообщения Issues/PR.

## Скачивание и обновление на Android

После успешного подписанного запуска:
https://github.com/dmitriymaksimowitch-ctrl/mobile-card-game/releases/latest/download/card-club-latest.apk

Сохраните APK на телефон и откройте его: Android предложит обновить
установленное приложение «Карточный клуб 1» поверх версии 1.0.0.
Удалять старую версию не требуется.

При каждой следующей правке в `main` GitHub Actions автоматически создаёт
новую подписанную сборку. Android versionCode увеличивается автоматически,
поэтому последующие APK обновляют предыдущие. Не меняйте
`package/unique_name` и приватный ключ подписи. Система проверяет SHA-256
сертификата и не публикует сборку при несовпадении.

**Внимание:** сейчас репозиторий GitHub публичный, поэтому и опубликованные
через GitHub Releases APK будут публично доступны. Перед добавлением секрета
и запуском подписанной публикации решите, подходит ли это.

## Диагностика

Сборка: `.github/workflows/android-apk.yml`.
Результаты и ошибки: `Actions → Build Card Club Android APK`.
Время и статус зависят от GitHub Actions. Реальный интерфейс нужно проверить
на Android отдельно: успешный экспорт и прохождение тестов не гарантируют,
что визуальное расположение карт идеально на любом устройстве.
